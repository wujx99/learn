# Knowledge

Reusable deep-learning knowledge is organized as one focused topic per directory.
Each topic has exactly one canonical learning document:

```text
knowledge/
  <topic-slug>/
    README.md                 # Concept-led topic, or
    <topic-slug>.ipynb        # Code-led topic
    assets/                   # Only when directly used
```

Use Chinese for explanations by default and PyTorch for code unless another
framework is requested. Extend an existing canonical document when revisiting a
topic instead of creating disconnected fragments.
